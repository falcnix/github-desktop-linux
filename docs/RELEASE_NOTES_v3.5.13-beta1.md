# GitHub Desktop for Linux, v3.5.13-beta1

Unofficial Debian/Ubuntu `.deb` build of
[GitHub Desktop `3.5.13-beta1`](https://github.com/desktop/desktop), on Electron
`42.0.1`.

## Install

```bash
sudo apt install ./github-desktop_3.5.13.beta1-1_amd64.deb
```

## Verify

```
SHA-256: 1c4a0646d2a748839770f8bb71078fd05762cb03f3c67ebe45b7ab0ebb013cd0
```

```bash
sha256sum -c github-desktop_3.5.13.beta1-1_amd64.deb.sha256
```
